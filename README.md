# MaaWos · WOS 助手

**远程随手操作，多个账号一处安排。**

MaaWos 是《无尽冬日》Android 助手。通过同账号设备实时看屏、点击与滑动，远程安排任务；为不同账号保留独立分身，再用游戏进程脚本完成重复日常。自动化在 Android 执行设备本地运行，无需电脑持续连接。

**[预览与下载](https://nas-wos.zzming.cn:16606/download/) · [GitHub Releases](https://github.com/zzmgoing/MaaWosDist/releases) · [使用反馈](https://nas-wos.zzming.cn:16606/feedback/) · [爱发电主页](https://afdian.com/a/maa-wos)**

## 核心功能

### 实时远控，随手掌控

- **实时看屏与操作**：连接同账号在线 Android 设备，点击、滑动或使用系统按键，支持全屏查看；无需先启动游戏。
- **任务远程安排**：管理目标设备的任务、分组与定时，查看执行结果，按需进入画面手动操作。
- **画面随网络调节**：H.264 支持硬件与软件编码，按网络情况调节码率；短暂中断恢复有效连接，不补发中断期间的触摸。
- **控制端无需 Root**：被控 Android 需要 Root 并开启被控模式，双方登录同一账号。

### 分身独立，切换从容

- **一个分身，一份数据**：分身数据独立，首次分别登录，为不同账号保留各自的游戏空间。
- **名称自定义，启动更直接**：在分身列表中改名、启动与管理，也可创建桌面快捷方式。
- **任务跟着分身走**：将任务目标绑定到指定分身，配合自建分组与定时，分别保存任务参数。
- **按账号权益使用**：VIP 月卡 ¥9.9／31 天，最多登录 2 台设备、全账号共 1 个分身；SVIP 月卡 ¥19.9／31 天，最多登录 5 台设备、分身数量不限。后台单独设置的额度优先。创建分身无需 Root；本机自动化与被控端需要 Root，控制端无需 Root。

**使用小贴士：前 66 名 VIP 用户永久升级 SVIP，享受不限数量的分身。** 按首次正式月卡到账顺序分配名额，永久升级的是会员等级，月卡仍需保持有效。

微信、抖音登录需通过对应分身菜单安装登录应用，在同一空间完成登录。建议仅用于登录，频繁使用可能导致账号异常或占用较多存储。

### 日常任务，集中处理

统帅签到、免费宝箱、登录好礼、探险领取、联盟捐献、联盟宝箱、海岛领取协助、宠物寻宝、商店购买、邮件清理和每日任务领取等常用操作，可单独执行，也可放入分组按顺序运行。

### 采集与活动，按需配置

- **自动灯塔、自动采集、自动野兽**：按任务参数执行日常资源与野外流程。
- **自动竞技场**：读取游戏数据，按配置选择对手、完成挑战并领取每日宝箱。
- **打熊、集结巨兽、物品集结、联盟总动员**：分别配置活动任务，配合分组与定时安排使用。
- **王城争夺**：提供刷分、低保、车身三种模式，支持运行中切换，按本期军情、编队和队列执行。
- **角色列表**：在「设置 → 设备 → 角色列表」保存角色，运行或定时时选择角色与顺序，每个角色完整执行一遍公共任务；已有「设置角色」任务保持兼容。

### 自建分组与定时执行

把常用任务组成自己的日常清单，调整成员和顺序，为分组保存独立参数。单项任务与分组均支持定点、按间隔执行，也可设置间隔天数，安排隔天开放的活动。执行记录可查看运行结果与失败原因。

### 随手可用的小工具

| 小工具 | 用途 |
| --- | --- |
| 金手指连点器 | 悬浮按钮双击开始连点，单击或拖动停止 |
| 宠物洗炼 | 选择单洗或双洗、目标词条与洗炼石消耗上限 |
| 堡垒抢车 | 在堡垒、要塞的集结列表中辅助抢车 |
| 自动兑换 | 独立维护多角色名单，每天查询官方兑换码并通过官方网页接口兑换 |

### 让界面也合自己的习惯

支持浅色与深色主题、背景相册与自定义照片，以及经典或液态玻璃导航。任务配置、权限管理、应用更新和反馈入口都能在 App 内完成。

任务通过游戏进程脚本在 Android 执行设备本地运行。远控需双方联网传输画面和输入；账号登录、授权同步与应用更新也使用网络服务。

## 下载与使用

1. 在[预览与下载页](https://nas-wos.zzming.cn:16606/download/)查看应用界面并下载最新 APK，手机支持横滑截图、点击放大与底部快捷下载；也可前往 [Releases 发布页](https://github.com/zzmgoing/MaaWosDist/releases)，在版本的 **Assets** 中下载。
2. 安装后使用邮箱验证码登录，在「设置 → 我的账号」查看授权与分身权益。
3. 本机执行任务或作为被控端时，在「设置 → 权限」授予 Root；仅控制其他设备无需本机 Root。
4. 在分身页创建并登录游戏，或使用原游戏。选择任务并确认目标与参数；需要批量执行时建立分组，需要自动触发时添加定时。

支持 **Android 10 及以上的 ARM64 设备**；本机自动化与被控端需要 **Root**，无线调试不再作为自动化通道。游戏进程脚本当前适配 **无尽冬日 1.16.12（147）**，未适配任务会提示不可用。模拟器需支持 ARM64 应用与 Root。运行时需联网确认登录与授权。定时触发时设备须处于可直接操作的状态，密码、指纹或图案锁屏时无法执行；错过的定时不会补跑。请按提示授予精确闹钟与后台运行所需权限。

当前正式最新版为 **0.8.12（versionCode 27）**。沿用原正式签名，可从 0.8.11 覆盖安装。修复红米／KernelSU 前台检查长时间等待，改善本机任务与快捷栏响应；自动治疗和自动帮助跟随当前在线角色，返回前台恢复摘要。通知权限即时刷新、Root 自动补齐和前台服务分组，默认网络切换与应用启动兼容一并加固；修复常驻工具阻塞静默更新和除雪整数油耗边界。

Android 正式包已通过签名、APK 对齐、红米主用户覆盖安装和安装摘要核对；NAS 与 GitHub 完整回下载的版本、大小、SHA-256 及签名一致。红米 Release 已完成大小号各 17 项日常、小号零库存火箭除雪第 1～3 区及装备升级、大号三种策略各一局钓鱼；实际动作、回执与到账均核对。最终包采集约 1.79 秒进入执行，快捷栏巨兽约 1.57 秒启动、7.71 秒确认实际集结。其他机型完整任务、后续除雪区域、库存火箭及长时间稳定性仍待现场验收。iOS 源码仍为 0.8.11（26），本次未发布；TestFlight 仍待 Apple 团队与上传凭据，iPhone 可使用[官网网页版](https://nas-wos.zzming.cn:16606/control/)管理同账号 Android 设备。

**模拟器兼容范围**：MuMu Android 12 已验证安装、登录、Root、实时画面、点击、滑动与短暂中断恢复；Android 15 已验证安装、登录与 Root 启动。模拟器游戏进程任务、高负载游戏画面和长时间稳定性仍待用户测试。遇到问题请通过使用反馈提供模拟器版本、Android 版本与复现步骤。旧版界面截图用于功能示意，具体显示以当前 App 为准。

## 邀请朋友

在 App「设置 → 邀请新用户」复制邀请码或分享邀请链接。朋友下载并使用邮箱登录后，在同一页面填写邀请码，双方各得 **7 天 VIP 授权**，授权天数可累加。每个账号仅可填写一次邀请码；下载页会展示链接携带的邀请码并提供复制按钮，链接不会自动绑定账号。
