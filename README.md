# MaaWos 无尽冬日助手

在 Android 手机上运行日常、采集、打熊等任务。任务可以分组和定时，也可以用浏览器远程操作手机。

[官网下载](https://nas-wos.zzming.cn:16606/download/) · [GitHub 下载](https://github.com/zzmgoing/MaaWosDist/releases/latest) · [打开网页版](https://nas-wos.zzming.cn:16606/control/)

## 功能

- **日常任务**：统帅签到、领取免费宝箱、正中靶心、银行存储、登录好礼、商店购买、探险领取、联盟捐献、联盟宝箱领取、海岛领取协助、领主律令-生产、宠物寻宝、收兵练兵、自动灯塔、自动采集、自动集结、每日任务领取、自动竞技场、炼晶实验室、邮件清理。
- **联盟战争**：物品集结、集结巨兽、自动野兽、打熊。
- **限时活动**：逐光之旅、欢乐大乱斗、燃霜矿区、最强王国、决战王城、联盟总动员、梦境寻忆、钓鱼锦标赛、除雪小分队、峡谷会战、兵工厂、缤纷刨冰铺。
- **小工具**：自动兑换、宠物洗炼、堡垒抢车、自动治疗、自动帮助、自动抢红包、抢堡垒/王城首占、查领主坐标。
- **起号养号**：快速起号、小号养成、大号托管，均为 Beta。

## 使用方法

1. 在 Android 10 或更新版本的 ARM64 手机上安装 APK，用邮箱验证码登录。
2. 运行游戏任务或被远控的手机需要先完成 Root。在 MaaWos 首页点「Root 权限」，再点「请求 Root 权限」，并在 Root 管理器中允许。
3. 登录原版游戏或分身。在 MaaWos 首页选任务，填写参数后点「立即运行」。

可以选择角色和执行顺序，把常跑的任务加入分组，设置每天、按间隔或仅一次运行。执行结果可在运行记录查看。定时需要允许后台运行和精确闹钟。设备有密码锁屏时，先解锁。

需要分身时，到「设置 → 分身」创建，在对应分身的菜单里用微信或抖音扫码登录。

要远控手机，先在执行任务的手机上打开「设置 → 设备」，开启「允许远端控制」，再用电脑或手机浏览器登录同一个账号。网页版也能管理分组和定时，浏览器所在设备无需 Root。

当前适配无尽冬日 1.16.12（147）。会员和设备额度可在「设置 → 我的账号」查看，更新可在「设置 → 关于」检查。
