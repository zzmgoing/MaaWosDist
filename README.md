# MaaWos 无尽冬日助手

在 Android 手机上运行日常、采集、打熊等任务。任务可以分组和定时，也可以用浏览器远程操作手机。

[官网下载](https://nas-wos.zzming.cn:16606/download/) · [GitHub 下载](https://github.com/zzmgoing/MaaWosDist/releases/latest) · [打开网页版](https://nas-wos.zzming.cn:16606/control/)

## 功能

- **日常和联盟**：签到、领宝箱和登录奖励、银行存储、商店购买、探险奖励、联盟捐献、联盟宝箱、海岛协助、领主律令、宠物寻宝、收兵练兵、每日任务奖励、炼晶实验室、邮件清理。
- **采集和战斗**：自动灯塔、采集、打野兽、巨兽和物品集结、打熊、竞技场、自动集结、联盟总动员。
- **限时活动**：逐光之旅、欢乐大乱斗、燃霜矿区、最强王国、决战王城、峡谷会战、兵工厂、正中靶心、缤纷刨冰铺。
- **小工具**：梦境寻忆、宠物洗炼、堡垒抢车、钓鱼锦标赛、除雪小分队、自动治疗、自动帮助、自动兑换、自动抢红包、抢堡垒／王城首占、查领主坐标。
- **分身和多角色**：原版游戏和分身可以分别登录。在任务中可以选择角色和执行顺序。快速起号、小号养成和大号托管为 Beta 功能。
- **分组、定时和远控**：可以把任务放进分组，按天、按间隔或定时执行一次，并查看运行记录。同一账号下可以用网页查看和操作手机，也可以远程安排任务。

## 使用方法

1. 在 Android 10 或更新版本的 ARM64 手机上安装 APK，用邮箱验证码登录。
2. 在「设置 → 权限」授予 Root。本机运行游戏任务或被其他设备远控时需要 Root。
3. 登录原版游戏或分身。在 MaaWos 首页选任务，填写参数后点「立即运行」。常跑的任务可以加入分组，再设置定时。

定时执行需要允许后台运行和精确闹钟。设备有密码锁屏时，先解锁。

需要分身时，到「设置 → 分身」创建，在对应分身的菜单里用微信或抖音扫码登录。

要远控手机，先在执行任务的手机上打开「设置 → 设备」，开启「允许远端控制」，再用电脑或手机浏览器登录同一个账号。网页版也能管理分组和定时，浏览器所在设备无需 Root。

当前适配无尽冬日 1.16.12（147）。会员和设备额度可在「设置 → 我的账号」查看，更新可在「设置 → 关于」检查。
