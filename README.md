## 产品特点

- **实时远控**：同账号设备实时看屏、点击、滑动、系统按键与全屏操作，远程管理任务、分组和定时。
- **独立分身**：各自保存登录与数据，支持改名和桌面快捷方式。
- **角色编排**：选择原版或分身中的角色与执行顺序，每个角色依次运行公共任务。
- **分组与定时**：自由组合任务、保存独立参数，支持每日、间隔和一次性定时，查看执行结果与失败原因。
- **游戏内快捷栏**：在游戏内配置并启停战斗及辅助工具，自动治疗与帮助可并行监听。
- **本机运行与自动更新**：进程脚本在 Android 执行设备运行，无需电脑持续连接；Root 设备空闲后可自动安装更新。
- **个性外观**：浅色／深色主题、自定义照片背景、经典／液态玻璃导航。

梦境寻忆支持自动寻物与提示；钓鱼支持普通／宝藏关卡和高价值／图鉴／均衡策略；除雪逐区规划；宠物洗炼可设目标词条与消耗上限。自动兑换每天查询官方兑换码，为名单中的角色兑换，无需登录游戏、Root 或切号。

## 开始使用

1. 下载 APK，在 **Android 10+、ARM64** 设备上安装，使用邮箱验证码登录。
2. 本机自动化或作为被控端时授予 **Root**；仅远程控制其他设备无需 Root，iPhone 和电脑可使用网页版。
3. 登录原版游戏或分身，选择角色与任务参数，按需添加分组和定时。

当前适配 **无尽冬日 1.16.12（147）**。登录、授权及远控需联网；定时需允许精确闹钟与后台运行，设备须可直接操作，安全锁屏会阻止执行，错过的定时不补跑。部分限时活动完整流程、多角色切换执行及模拟器游戏任务仍待现场验收，实际范围以[版本说明](https://github.com/zzmgoing/MaaWosDist/releases/latest)为准。
